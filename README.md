# Pincel Suave Krita GalaxilliPipo
Um pincel suave e feito para desenhos para Krita, ele está em estado beta.
Este pincel foi feito para ser suave e bom para desenhos.
Este pincel está em estado **Beta**, portanto procure por error ou ideias de atualizações.
## Não sabe como usá-lo no krita?
Passo a passo para começar a usar.
1. Abra a aba configurações na barra superior esquerda, lá em cima.
2. Após abrir vocẽ verá a opção **"Gerenciar recursos..."**, clique nesse botão.
3. Depois procure pelo botão **"Importar recursos"**.
4. Aparecerá um menuzinho para você achar seu arquivo .bundle baixado. Se você não baixou baixe agora o repositório.
5. Depois de achar o arquivo clique duas vezes com o botão esquerdo do mouse e o pincel deve aparecer. E pronto.
